HSRTimer Microsoft Store 字体包 v1.0

此字体包可选装，需要支持 HUD 字体的 HSRTimer Microsoft Store 0.1.3-pre。

1. 右键单击 ZIP，选择“全部解压缩”。
2. 在游戏中按 Home（默认键），打开 HSRTimer 设置。
3. 在 About 页面点击“Open Data Folder”。如果没有 fonts 文件夹，请新建一个。
4. 把解压后的 fonts 文件夹中的五个 .bundle 文件复制到第 3 步的 fonts 文件夹。遇到同名文件时，请保留原文件或先备份再替换。
5. 在 HSRTimer 中打开 界面 → 计时器HUD → HUD 字体。
6. 点击“重新加载字体列表”，选择字体，再点击“应用并保存”。

如果不再使用字体包，请选择“默认 (IMGUI)”，再点击“应用并保存”。
退出游戏，只删除 fonts 文件夹中本字体包的 .bundle 文件。请保留设置和个人纪录。
