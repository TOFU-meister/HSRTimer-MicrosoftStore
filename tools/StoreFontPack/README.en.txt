HSRTimer Microsoft Store Font Pack v1.0

This optional pack requires HSRTimer Microsoft Store 0.1.3-pre with HUD Font support.

1. Right-click the ZIP and choose Extract All.
2. In the game, open HSRTimer settings with Home (default key).
3. In About, choose Open Data Folder. Create a folder named fonts if needed.
4. Copy the five .bundle files from the extracted fonts folder into that fonts
   folder. Keep or back up any files with matching names before replacing them.
5. In HSRTimer, open Interface > Timer HUD > HUD Font.
6. Choose Reload font list, select a font and press Apply & Save.

To remove the pack, select Default (IMGUI) and press Apply & Save. Quit the
game, then delete only this pack's .bundle files from the fonts folder.
Keep your settings and PB files.
