HSRTimer Microsoft Store フォントパック v1.0

このパックは任意です。HUDフォント機能付きの HSRTimer Microsoft Store 0.1.3-pre が必要です。

1. ZIPを右クリックし、「すべて展開」を選びます。
2. ゲーム内で Home キー（初期設定）を押し、HSRTimerの設定を開きます。
3. Aboutページの「Open Data Folder」を押します。開いた場所に fonts フォルダーがなければ作ります。
4. 展開した fonts フォルダーの .bundle ファイル5個を、手順3の fonts フォルダーにコピーします。同名ファイルは残すか、バックアップしてから入れ替えてください。
5. HSRTimerで Interface → Timer HUD → HUDフォント を開きます。
6. 「フォント一覧を再読み込み」を押し、好きなフォントを選んで「適用して保存」を押します。

使わなくなったら「標準（IMGUI）」を選んで「適用して保存」を押します。
ゲームを終了し、fonts フォルダーからこのパックの .bundle ファイルだけを削除します。設定やPBはそのまま残してください。
