# HSRTimer Microsoft Store v0.1.3-pre

公開用リリースノート案 / Draft release notes / 发布说明草案

- `HSRTimer-v0.1.3-pre.dll`
- `HSRTimer-MicrosoftStore-FontPack-v1.0.zip`（任意 / optional / 可选，40.50 MiB）
- [導入・更新 / Install and update / 安装和更新](INSTALL-v0.1.3-pre.md)

## 日本語

- **One Key Retry** の行き先に、名前に加えて数値のマップIDを指定できます。通常・Extraの対象を確認できます。[マップID一覧](../RETRY-MAP-IDS.md)
- **HUDフォント** を選び、Normal／Boldとプレビューを確認して保存できます。次回起動時に復元し、指定したフォントが使えないときは標準表示で続行します。外部フォント5種のパックは任意です。
- 診断用操作は通常の設定画面から非表示になりました。PBの自動バックアップは従来どおり任意で、初期値はOFFです。

Microsoft Store／Xbox PC版向けです。更新はゲームを終了し、旧DLLを外して新版を `BepInEx\plugins` 直下へ置きます。設定・レイアウト・PBは引き継げます。

## English

- **One Key Retry** accepts a numeric map ID as well as a map name. See the [map ID list](../RETRY-MAP-IDS.md) for normal and extra levels.
- Choose a **HUD font**, preview it in Normal or Bold, and save it. The selection is restored at startup. The default display takes over when the selected font is unavailable. The five-font pack is optional.
- Diagnostic controls are hidden by default. Automatic PB Backup remains optional and off by default.

For the Microsoft Store / Xbox PC game. To update, close the game, remove the old DLL and place the new one directly in `BepInEx\plugins`. Keep your settings, layout and PB files.

## 简体中文

- **一键重试**支持使用地图名称或数字 ID 指定关卡。[地图 ID 列表](../RETRY-MAP-IDS.md)
- 可以选择 **HUD 字体**、预览常规或粗体并保存。下次启动会恢复选择；字体不可用时会使用默认显示。五款字体的字体包可选装。
- 默认隐藏诊断操作。PB 自动备份仍为可选功能，默认关闭。

适用于 Microsoft Store／Xbox PC 版游戏。更新时退出游戏，移除旧 DLL，将新版直接放入 `BepInEx\plugins`。保留现有设置、布局和 PB 文件。
