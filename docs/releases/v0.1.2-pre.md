# HSRTimer Microsoft Store v0.1.2-pre

Human: Fall Flat Microsoft Store／Xbox PC 版向けの非公式プラグインです。

## 対応環境と導入

Windows x64、Unity 2019.4.24f1、BepInEx 6.0.0-be.793 Unity IL2CPP Windows x64 に対応します。ゲームを終了し、Assets の **`HSRTimer-v0.1.2-pre.dll`** をダウンロードして `BepInEx\plugins` の直下へ置いてください。旧版 DLL は外してください。GitHub の **Source code (zip)** は導入には使いません。

**TwilightInputOverlay Microsoft Store `0.1.1-pre`** と併用できます。両方導入したら Home で HSRTimer の設定画面を開き、**Input Overlay** タブを選びます。詳しい手順は [README](https://github.com/TOFU-meister/HSRTimer-MicrosoftStore/blob/v0.1.2-pre/README.md) を参照してください。

## 変更点

- **PB の自動バックアップは既定で OFF**。Home → General → Automatic PB Backup（PBの自動バックアップ）で切り替えます。ON では PB 更新前のバックアップを保存し、OFF でも通常の PB 保存・読み込みは使えます。既存バックアップは残り、設定は `settings.ini` に保存されます。中断時の復旧処理と通常のマーカー編集時のバックアップは維持しています。
- 初回テスト版から、外部設定タブ API、Input Overlay タブ連携、バージョン付き DLL 単体配布を追加し、導入説明を更新しました。

## 確認結果と既知の制限

Windows 実機では両プラグインの読み込み、HSRTimer の設定画面と Input Overlay タブ、Raining Keys の連続例外解消、Train の IL PB 更新が確認されています。最新ログにエラーや実行時例外の出力はなく、起動時の Il2CppInterop 警告は残っています。PB バックアップの ON/OFF によるファイル生成の違いは自動テストで確認済みです。

この配布は Microsoft Store／Xbox PC 版向けです。BepInEx は別途導入してください。
