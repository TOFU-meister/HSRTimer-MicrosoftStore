# HSRTimer Microsoft Store v0.1.0-pre

Human: Fall Flat の Microsoft Store / Xbox PC 版向けの初回テストリリースです。正式版の前に実際のプレイ環境で試してもらうための **Pre-release** です。

## 先行ビルドで実機確認済み

- BepInEx 6 IL2CPP での起動、タイマー HUD と設定画面の表示
- Mansion の IL PB 保存と、ゲーム再起動後の読み込み
- ドキュメントへの設定・PB 保存と、About → **Open Data Folder**
- 以前の IL2CPP 登録エラーの解消と、専用リポジトリへの更新確認

## 既知の制限と確認中の項目

- Windows x64 の Microsoft Store / Xbox PC 版が対象です。
- Windows のドキュメントへ保存できない環境では LocalAppData を使います。OneDrive などのフォルダー構成ごとの実機確認は継続中です。
- 日本語 IME の直接入力、全ステージ・全カテゴリでの計測、全タグの組み合わせは確認中です。
- プリセットは HUD レイアウトの保存・復元に対応します。
- 更新確認は安定版のみが対象です。このテスト版は手動で導入してください。

## 導入と不具合報告

別途 BepInEx **6.0.0-be.793 IL2CPP Windows x64** が必要です。ZIP に同梱の README.txt または [導入方法](https://github.com/TOFU-meister/HSRTimer-MicrosoftStore/blob/v0.1.0-pre/README.md#インストールと更新) を参照してください。

不具合は [Issues](https://github.com/TOFU-meister/HSRTimer-MicrosoftStore/issues) に、ゲーム・プラグインのバージョン、再現手順、`BepInEx/LogOutput.log` の関連部分を添えて報告してください。Windows のユーザー名などは伏せてください。
