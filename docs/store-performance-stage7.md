# Store 第7段階 — 長時間の FPS・メモリ調査

対象は HSRTimer 0.1.3-pre、TwilightInputOverlay 0.1.2-pre、Human: Fall Flat 1696732、Unity 2019.4.24f1、BepInEx 6.0.0-be.793 です。

## 実機とコードの確認結果

約13分の圧縮バンドル試験では両プラグインが読み込まれ、Font #33406 と1件の Bundle が維持されました。Material とアトラスは最後の診断でも有効、復旧試行0件、PB保存5件、Error ログ0件でした。FPS とメモリは未計測です。Dark 固有の負荷、フォント描画、マスク生成、保存時の I/O などの因果はこのログだけでは判断できません。

| 点検箇所 | 確認内容 |
| --- | --- |
| Timer HUD / IMGUI | GUIStyle は Awake で生成。従来は IMGUI の複数イベントで同じ描画準備を繰り返していました。Store 版の表示専用 HUD を Repaint 限定にしました。1行ごとのソート用リスト、文字列、文字ごとの GUIContent・測定などの短命な割り当ては残ります。 |
| 外部 Font | Font とバンドルは保持済み候補に紐付き、Material・アトラス参照は寿命監視で更新されます。500msの有効性監視は保持対象があるときだけ実行。通常プレイ時に RequestCharactersInTexture を明示的に呼ぶ経路や、textureRebuilt のイベント登録はありません。字形のリクエストは診断ボタンのみです。ネイティブのアトラス再構築は Unity の描画処理に依存します。 |
| Reflection | Bundle を明示的に開くか復旧するときと、診断操作で使用。健全な Font の定期監視では通常の Unity ラッパーを参照します。FPS 診断を有効にした場合のみ任意の Unity メモリ API を5秒ごとに照会します。 |
| Subsegment / Markers | ステージのサンプルは設定された上限と区切りで整理されます。マルチレベルのサンプルはランの間保持されます。Markers の feed は試行変更時の初回トリガーで切り替わり、シーン参照は整理されます。PB 更新は同期的なシリアライズ・書き込みがあるため一時的なスパイクの候補。保存トランザクションの時間も採取します。 |
| Overlay 通常キー | 形状キャッシュは96件・2,097,152ピクセル。表現に必要なフェードのみを保持し、辞書2個を使い回します。シーン間で保持される形状は上限内です。 |
| Raining Keys | 形状キャッシュは96件・2,097,152ピクセル。バーはキーごとに最大32件で、期限切れを除去。毎フレームの辞書・一時リストと、未押下スロットの Rain 生成を削減しました。高さ変化によるマスク生成の負荷は残ります。 |
| Mouse Overlay | 形状キャッシュは32件・2,097,152ピクセル。軌跡は位置・速度などの状態から描画し、無制限の軌跡履歴を保持しません。動きが広い範囲の形状を使う場合は再生成と追い出しの候補です。 |

既存の寿命監視、テクスチャ保護、破棄・再試行ロジックは維持しました。累積的なリークを示す証拠は得られていません。

## Windows での採取

1. HSRTimer は **Home → About → Start performance capture**。Overlay は **Input Overlay → Debug → Start overlay performance capture**。Overlay 単独時は独立設定画面の Debug を使用します。いずれも起動時は OFF で、再開時に前回サンプルが消えます。
2. 設定画面を閉じて計測します。速度、画質、FPS 上限、VSync、解像度、マップと移動ルートを同じにそろえ、各条件で同じ時間を測ります。長時間時の低下なら、開始直後と同程度に温まった後で同じ区間を再走します。
3. **Stop** を押して **Export** します。各プラグインのデータフォルダーに timer-performance.csv と overlay-performance.csv が出ます。再エクスポート前に条件名を付けてコピーすると比較できます。UTC またはゲーム起動後経過秒で突き合わせます。

| 条件 | 試し方 |
| --- | --- |
| A | Restore IMGUI で標準フォント |
| B | 非圧縮バンドル1件を読み込み、目視確認して HUD へ適用 |
| C | LZ4HC バンドル1件を読み込み、同サイズで適用 |
| D | バンドルを読み込み、HUD には適用しない |
| E | 外部フォントを適用した状態で Timer HUD を非表示 |
| F | 同じフォント条件で通常キー / Raining Keys / Mouse Overlay を切り替える。Raining Keys は通常キー HUD の表示に依存するため、Rain 単体の差は通常キー表示を維持して比較。Mouse の背景も個別に確認 |

HSRTimer 単体と併用も比較できます。Overlay 単体は Overlay CSV の平均 FPS を使用します。ゲームだけの基準測定では同じ外部 FPS 計測を各ケースでも使用してください。

## CSV の読み方

- Update 1回を1フレームとして Time.unscaledDeltaTime を収集します。5秒単位で集計。Timer の平均 FPS はフレーム数を合計フレーム秒で割った値、p95/p99 は nearest rank、1% Low は遅い側1%の平均フレーム時間の逆数です。percentile_frames が frames より小さい場合、分位値は直近4096フレームに限ります。
- 最大360行（約30分）を保持します。停止時の未完了ウィンドウは収録外。CPU は累積プロセス CPU 時間なので行間の差分を使います。GC は .NET の累積回数です。未提供の Unity メモリ情報は空欄になります。
- HUD と Overlay の計測値はウィンドウ内の CPU 側呼び出し時間の合計です。GPU 完了時間とは別です。collect_ms は診断集計とサンプリングのおおよその時間。PB は実ストレージのトランザクション範囲で、事前のシリアライズは含みません。
- 外部 Font とアトラスの ID・サイズは5秒ごとに観測します。observed_atlas_changes は同じ Font の ID／寸法の変化で、同じアトラス内の字形更新やサンプル間で完結した再構築は数えません。標準 IMGUI のアトラス欄は空欄です。
- Overlay のテクスチャ数・ピクセル数は現在値、作成・破棄要求・無効ヒット・即時再生成は累積値です。破棄要求は Unity が解放を完了した件数とは別です。差分で生成頻度を比較してください。
